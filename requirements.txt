# Pinned to the versions the Docker image was tested against (pip freeze of a
# known-good build). The old open ranges (`fastapi>=0.110`, ...) let a routine
# image rebuild silently pick up a new transformers/pydantic that breaks the
# GPT-2 dissection internals this code depends on (attn_implementation="eager",
# the Conv1D weight layout in neuroscope/model.py, mlp.c_proj weights).
#
# To upgrade: bump ONE pin, `docker compose up --build`, run `make test`, then
# re-run the API parity check. Never re-resolve the whole set at once.
#
# Note for the plain-python path (README option A): `torch==2.14.1` resolves to
# the default PyPI build, which drags in CUDA deps on Linux. The Dockerfile
# pre-installs the CPU wheel (2.14.1+cpu) from download.pytorch.org, which
# satisfies this pin, so containers stay lean.
